### 1.2 技能描述

每个技能按固定顺序逐行写, 不用表格; 骰子费用一行, 充能另起一行; 没有充能或被动技能时省略对应行.

敲打修理法
普通攻击
1 个水元素骰 + 2 个任意元素骰
> 造成2点物理伤害。

妙思捕手
元素战技
3 个水元素骰
> 造成2点水元素伤害，生成1层敏捷切换。如果手牌中有卡牌具有赋能，则改为造成3点水元素伤害.

精密水冷仪
元素爆发
3 个水元素骰
2点充能
> 造成2点水元素伤害，召唤冷静一下鸭。

模块式高效运作
被动技能
> 【被动】我方卡牌被赋予赋能时：如果我方场上存在冷静一下鸭，则使其可用次数+1，否则自身获得1点充能。（每回合1次）

### 1.3 关键字展开

| 关键字 | 说明 | 在本卡哪里出现 |
|---|---|---|
| 赋能 | 无说明文字; 手牌卡状态, 布尔形态 (实现: `HAND_EMPOWERMENT`)  | 妙思捕手的条件, 模块式高效运作的触发 |
| 充能 | 角色使用"元素爆发"时, 需要消耗充能.角色使用"元素战技"或"普通攻击"后, 会获得1点充能. | 模块式高效运作获得 1 点; 精密水冷仪消耗 2 点 |
| 可用次数 | 每次触发这张牌的效果, 都会消耗 1 次"可用次数"; 耗尽后立刻弃置. | 模块式高效运作使冷静一下鸭可用次数 +1 |
| 水元素伤害 | 附着水元素, 可发生元素反应 (蒸发 / 感电 / 冻结 / 绽放 / 月感电...). | 妙思捕手 / 精密水冷仪的伤害 |

关联实体 (按名称) : 

| 名称 | 说明 | 在本卡哪里出现 |
|---|---|---|
| 敏捷切换 | 我方下次执行"切换角色"行动时: 将此次切换视为"快速行动"而非"战斗行动". (可叠加, 没有上限)  | 妙思捕手生成 1 层 |
| 冷静一下鸭 | 召唤物: 结束阶段造成 2 点水元素伤害; 可用次数 2. | 精密水冷仪召唤, 模块式高效运作查询 |

### 1.4 相关规则书条目摘录

> 规则书·进行行动 战斗行动[使用技能]: 
> 用元素骰支付所需的费用, 使我方"出战角色"使用技能攻击对方的"出战角色".
> 角色每次使用"普通攻击"或"元素战技"后, 会获得 1 点"充能".
> 角色"充能"达到上限后, 可以花费所有"充能"来使用威力强大的"元素爆发"!

> 规则书·游戏区域 IV 召唤物区: 
> 一些角色技能会在召唤物区生成"召唤物".召唤物区最多放置 4 个"召唤物".占满后, 无法生成新的"召唤物".

> 规则书·特殊词条 可用次数: 
> 每次触发这张牌的效果, 都会消耗 1 次"可用次数".
> "可用次数"耗尽后, 会立刻弃置这张牌.

## 4. 备注

### 4.1 坑

| 坑 | 说明 |
|---|---|
| 把指定水元素骰写成 `SameColor(1)` | `SameColor` 是"相同元素 n 个, 支付时定色"; 卡面指定水, 必须 `SpecificElement(Hydro, 1)` |
| 把任意元素骰写成 `SpecificElement(Hydro, 2)` | 任意元素 = `AnyColor(2)`; 锁成水会变严 |
| 版本同步时改卡牌内容 | D246: 只改 `card_game_version!` 的数字 |
| 新卡漏 `SOURCE_FILES` | 不编译失败, 但 `source_of` / `source_files` 找不到 |
| `ID` 不写 / 类型不对 | `card_source!` 的 `const _: CardId = ID;` 会编译失败 (D215, 故意设计)  |
| 标签写成字符串 / 数字 | D54: 标签是零大小类型, 一个标签一个文件; 卡牌只导入具体类型 |
| 把定义载体搬进 cards | `CardId` / `CostComponent` / `CharacterDef` / `SkillDef` 留在 definitions (D240 / D241)  |
| 把 `todo!()` 当可运行 | 调用即 panic; 测试刻意不调用效果体 |
| 照抄文件头注释 | 部分"未建"注释已过期 (`damage.rs`, 召唤物载体, 手牌状态已建)  |
