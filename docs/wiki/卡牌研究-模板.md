*本页范围: <名称> - 卡面描述 (中 / 英 + 关键字展开 + 相关规则书条目), 实现代码 (真实源码 / 计划代码 + 未实现清单), 实测记录与备注.*

> [!NOTE]
> 使用方式: 复制本页, 重命名为 `卡牌研究-<名称>.md`, 按 4 节填写, 在 [[卡牌研究]] §4 加一行.

> [!IMPORTANT]
> 写作硬规:
> 1. 不写外部数据路径与来源标注, 只写卡面文字本身;
> 2. 不写卡牌数字编号, 用名称叙述 (天赋名 / 状态名 / 角色名 / 事件名 / 召唤物名);
> 3. 不写关键字编号 (也是 ID), 用关键字名称或一句说明代替;
> 4. 两个形态不合并成一张表: 始基力：荒性形态与始基力：芒性形态各一张表, 名称写全称;
> 5. 被动技能没有费用字段, 不列费用行, 也不写表示无费用的行;
> 6. `§1.1` 不写用户点名要删的那个措辞;
> 7. 元信息逐行写: 类型 / 标签 / 费用等每项单独一行;
> 8. 只用半角标点 (术语 "始基力：荒性形态" / "始基力：芒性形态" 的全角冒号除外);
> 9. 描述照抄卡面文字, 保留原标点; 引用块是唯一保留全角标点的地方 (我们自己的话仍用半角);
> 10. 讲到哪段能力就紧跟着贴那段真实源码, 不堆到页尾, 不只给链接;
> 11. 代码贴全文, 不确定写 "待实测", 不要编;
> 12. 技能不用表格: 每个技能三行式: 技能名 / 技能种类 (普通攻击 / 元素战技 / 元素爆发 / 被动技能 / 天赋, 不加种类前缀) / ">" 照抄卡面描述; 被动不列费用, 费用单独一行; 模式也按三行式;
> 13. 代码块注释中的关键字编号替换为名称, 并在代码块上方加一行注记; 代码行保持仓库原样.
> 14. 费用行完整写法: 禁止简写; 用 "x 个水元素骰 + n 个任意元素骰 / n 个相同元素骰"; 骰子费用与充能分行; 充能写 "x点充能"; 无充能不写 0; 被动技能整行省略.
