# 卡牌模板: 角色 (示例用芙宁娜)

> 中文 · [[卡牌研究-模板-EN|English]]

*本页范围: 各类牌的写法模板. 目前是角色模板 (含多形态角色); 事件 / 秘传 / 装备 / 支援 / 召唤物 / 状态的模板陆续补.*

> [!IMPORTANT]
> 通用硬规:
>
> 1. 不写卡牌编号, 不写关键字编号 (K 码), 不写数据文件路径;
> 2. 我们自己的话用半角标点与双引号; 卡面描述照抄原文, 保留原文标点;
> 3. 引用块里每一项单独一段: 行与行之间插一个空的 `>`, 否则渲染时会并成一行;
> 4. 代码围栏写成 ```rust (中间没有空格), 代码与仓库逐字一致; 未实现就贴计划代码并标 "未实现";
> 5. 被动技能不写费用, 不写充能;
> 6. 多形态角色: **每个形态单独一节, 技能各自完整重复**, 即使两个形态的技能同名也分开写, 不合并、不写 "同上".

## 写法说明

> [!WARNING]
> 连续多行 `>` 在 GitHub 上会并成同一段, 所以每一项之间要留一个空的 `>` 行.
>
> 代码围栏必须写成 ```rust, 中间加空格不会高亮.
>
> 技能按出现顺序排: 普通攻击, 元素战技, 元素爆发, 被动技能.
>
> 多形态角色: 每个形态各自一节; **两个形态的技能名即使完全一样, 也必须在各自形态下完整写出来**, 不许合并或写 "同上".
