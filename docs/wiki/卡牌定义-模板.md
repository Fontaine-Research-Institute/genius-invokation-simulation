# 卡牌模板: 角色 (示例用芙宁娜)

> 中文 · [[卡牌定义-模板-EN|English]]

*本页范围: 各类牌的写法模板. 目前是角色模板 (含多形态角色); 其它牌型陆续补.*

> [!IMPORTANT]
> 通用硬规:
>
> 1. 不写卡牌编号, 不写关键字编号 (K 码), 不写数据文件路径;
> 2. 我们自己的话用半角标点与双引号; 卡面描述照抄原文, 保留原文标点;
> 3. 描述一整段, 不许拆段; 只有元信息 (标签 / 上限 / 费用 / 充能) 才分行, 每项间留空 `>`;
> 4. **为 0 的消耗一律省略**: 0 个相同元素骰 / 0 个任意元素骰 / 0 点充能都不写, 整行为 0 就整行不写;
> 5. 代码围栏写成 ```rust (中间没有空格), 代码与仓库完全一致; 未实现就贴计划代码并标 "未实现";
> 6. 被动技能不写费用, 不写充能;
> 7. 多形态角色: 形态名在角色名之上; 角色名与技能每个形态各写一遍, 同名也照写.
> 8. 关键字写成链接: [[关键字-<名称>|<名称>]]; 不写裸关键字编号.

## 小结

角色模板用两个形态各写一遍角色名与技能, 元信息与描述一律用引用块逐行写.定义代码与实现代码分开, 每段代码上方标文件路径.

## 写法说明

> [!WARNING]
> 连续多行 `>` 在 GitHub 上会并成同一段, 所以元信息项之间要留一个空的 `>` 行.
>
> 代码围栏必须写成 ```rust, 中间加空格不会高亮.
>
> 多形态角色: 先写形态名, 再写角色名; 角色名与技能每个形态各完整写一遍.
>
> 0 消耗不写: 例如 "1 个水元素骰 + 2 个任意元素骰" 而不是把 0 个相同元素骰也列出来.
