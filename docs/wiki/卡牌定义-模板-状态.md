# 卡牌模板: 状态

> 中文 · [[卡牌定义-模板-状态-EN|English]]

*本页范围: 状态的写法模板; 与 [[卡牌定义-模板]] (角色) 同构.*

> [!IMPORTANT]
> 通用硬规:
>
> 1. 不写卡牌编号, 不写关键字编号, 不写外部数据路径;
> 2. 我们自己的话用半角标点与双引号; 卡面描述照抄原文, 保留原文标点;
> 3. 描述一整段, 不许拆段; 元信息每项一段, 中间留空 `>`;
> 4. 为 0 的消耗一律省略; 没有充能就不写充能行;
> 5. 代码围栏写成 ```rust, 定义代码与实现代码分开;
> 6. 非状态类卡名下方配卡面图, 图片下方固定两行版权; 状态类不配图; 技能图标不配图;
> 7. 状态类不配卡面图, 也不登记素材来源; 状态类型写角色状态或出战状态.
> 8. 关键字写成链接: `[[关键字-<名称>|<名称>]]`; 不写裸关键字编号.

```

// 示例状态实现代码
```

## 写法说明

> [!WARNING]
> 连续多行 `>` 会并成同一段, 所以元信息项之间要留一个空的 `>` 行.
>
> 代码围栏必须写成 ```rust, 中间加空格不会高亮.
>
> 为 0 的消耗整行省略, 不要写 0 个水元素骰或 0 点充能.
>
> 状态类不配卡面图, 也不登记素材来源.
>
> 技能图标一律不配图.

## 小结

状态模板与召唤物模板同构, 但状态类型写角色状态或出战状态, 且状态类不配卡面图, 不登记素材来源.可用次数与持续回合有则写.
