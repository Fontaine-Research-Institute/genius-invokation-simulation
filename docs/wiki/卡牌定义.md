## 1. 这个栏目是什么

**卡牌定义** 按牌型模板**程序生成**: 每张卡一页, 内容是卡面描述 + 定义代码 + 实现代码 + 缺图清单.

| 项 | 说明 |
|---|---|
| 内容 | 卡面 (自动配图 + 版权行) / 元信息 / 技能或效果 / 定义代码 / 实现代码 |
| 生成 | `python tools/gen-card-docs.py --all` (只生成已实现的卡); `--all-keywords` 生成关键字页 |
| 不写什么 | 卡牌编号, 裸关键字编号, 数据文件路径, 长篇逐步结算表 |
| 未实现的卡 | 默认不生成; 强制生成时代码块写 `// 未实现` |
