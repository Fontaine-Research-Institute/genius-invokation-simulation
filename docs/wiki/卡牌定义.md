---

## 1. 这个栏目是什么

卡牌定义按牌型模板**程序生成**. 每张卡一页, 页里依次是卡面图, 元信息, 定义代码, 实现代码. 生成器把仓库源码原样填进去, 所以页面和代码天然一致.

生成命令:

```bash
python tools/gen-card-docs.py --all
python tools/gen-card-docs.py --all-keywords
```

写完跑一次自查, 它会检查表格, 全角标点, 裸露编号:

```bash
python tools/check-docs.py
```

## 3. 已生成的卡页

目前只有已实现的卡才生成页面. 未实现的卡不生成, 避免空壳.

- [[卡牌定义-爱诺]]

## 4. 关键字

关键字共 127 个, 每个一页, 按名称索引见 [[关键字]].

卡牌页里提到关键字时写成链接, 例如 `[[关键字-充能|充能]]`. 点进去能看到 K 码, 效果说明与使用它的卡.

## 5. 图片与许可

卡面图放在 `assets/<牌族>/<编号>.jpg`, 页面自动引用并带双语版权行. 状态类与技能图标不配图.

## 小结

卡牌页是生成出来的, 别手改. 要改内容就改仓库代码或生成器, 然后重新生成.
