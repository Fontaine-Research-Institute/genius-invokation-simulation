### 模块式高效运作

> 被动技能

```rust
pub static SKILL_12164: SkillDef = SkillDef {
    id: SKILL_ID_PASSIVE,
    name: zh_only("模块式高效运作"),
    description: zh_only(
        "【被动】我方卡牌被赋予赋能时：如果我方场上存在冷静一下鸭，则使其可用次数+1，否则自身获得1点充能。（每回合1次）",
    ),
    kind: SkillKind::Passive,
    cost: SkillCost::FREE,

```

> 【被动】我方卡牌被赋予[[关键字-赋能|赋能]]时：如果我方场上存在冷静一下鸭，则使其[[关键字-可用次数|可用次数]]+1，否则自身获得1点[[关键字-充能|充能]]。（每回合1次）
