# Definitions Layer: Tags

> [[定义层-Tags|中文]] · English

*Scope: the tag system — one tag / one file / one zero-sized type, `TagText`, `Localized` / `Resolved`, and the single generated tag data `TAGS`.*

---

## 1. Responsibility

Tags are "one tag, one file, one zero-sized type" under the independent top-level `tags/` directory (D53 / D54). Text data exists exactly once, generated at compile time into `generated::TAGS`; the runtime identity is the field address (D67). There is no tag enum, numeric / string code, or lookup table.

## 2. Key concepts and types

| Concept | File | Notes |
|---|---|---|
| Tag type | `crates/definitions/src/tags/<family>/<type>/<tag>.rs` | Each tag is a `pub struct Xxx;` (ZST) and provides `data() -> &'static TagText` returning `&TAGS.<field>` |
| Directory grouping | `tags/action_card/{support,equipment,event}`, `tags/action_card/common`, `tags/character/{element,nation,arkhe}`, `tags/summon`, `tags/enemy`, `tags/status` | Grouped by family / type; a shared tag imports the single definition site only (D55) |
| `TagText` | generated by `crates/definitions/build.rs` into `OUT_DIR/generated_data.rs` | `{ name: Localized, description: Localized }`; description has no data this round and is always empty |
| `TAGS` / `Tags` | same | One field per tag; field name = the `rust` identifier in `terms.json` lowercased to snake_case; field access performs no lookup |
| `Localized` / `Resolved` / `Lang` | `crates/definitions/src/generated/localized.rs` | Four-language text; `get(lang)` returns `Exact / Fallback / Missing`, reporting missing languages explicitly |

## 3. Public entry points

| Entry | File | Notes |
|---|---|---|
| `pub struct Xxx;` | each tag file | Concrete tag type (ZST), imported at its final path |
| `data() -> &'static TagText` | each tag file | Returns `&TAGS.<field>`; no text literals |
| `Localized::{EMPTY, from_parts, from_all, slot, has, get}` | `generated/localized.rs` | Construct / read a language slot / read with three-state fallback |
| `Resolved::{text, is_exact, is_fallback, is_missing, fallback_from}` | same | Three-state accessors for missing languages |
| `generated::TAGS.<field>` | generated code | The single source of tag text |

**`crates/definitions/src/generated/localized.rs`**

*Keyword codes in comments have been replaced with names; code lines are unchanged.*

```rust
/// 底层是若干条 UTF-8 静态字符串；**保留富文本标记的原文**（<color>、关键字占位符 等），
/// 渲染在 generated::text 里做。字段直接按语言命名，取值走 get()（会报告回退）。
#[derive(Clone, Copy, PartialEq, Eq, Hash, Debug)]
pub struct Localized {
    /// 简体中文。
    pub zh_cn: Option<&'static str>,
    /// English。
    pub en_us: Option<&'static str>,
    /// 日本語。
    pub ja_jp: Option<&'static str>,
    /// 한국어。
    pub ko_kr: Option<&'static str>,
}
impl Localized {
    /// 一条文本都没有。
    pub const EMPTY: Localized = Localized {
        zh_cn: None,
        en_us: None,
        ja_jp: None,
        ko_kr: None,
    };

    /// 由 4 个语言槽位构造（生成代码 / 常量用）。
    pub const fn from_parts(
        zh_cn: Option<&'static str>,
        en_us: Option<&'static str>,
        ja_jp: Option<&'static str>,
        ko_kr: Option<&'static str>,
    ) -> Localized {
        Localized {
            zh_cn,
            en_us,
            ja_jp,
            ko_kr,
        }
    }

    /// 4 语齐全时构造。
    pub const fn from_all(
        zh_cn: &'static str,
        en_us: &'static str,
        ja_jp: &'static str,
        ko_kr: &'static str,
    ) -> Localized {
        Localized {
            zh_cn: Some(zh_cn),
            en_us: Some(en_us),
            ja_jp: Some(ja_jp),
            ko_kr: Some(ko_kr),
        }
    }

    /// 取该语言槽位的值（match，不用下标）。
    pub const fn slot(self, lang: Lang) -> Option<&'static str> {
        match lang {
            Lang::ZhCn => self.zh_cn,
            Lang::EnUs => self.en_us,
            Lang::JaJp => self.ja_jp,
            Lang::KoKr => self.ko_kr,
        }
    }

    /// 该语言是否有文本。
    pub const fn has(self, lang: Lang) -> bool {
        self.slot(lang).is_some()
    }

    /// 取该语言的**渲染前原文**；缺语言时**显式**报告回退。
    ///
    /// 回退顺序固定 ZhCn → EnUs → JaJp → KoKr 中第一个有值的语言；一个都没有时 Missing。
    pub const fn get(self, lang: Lang) -> Resolved {
        if let Some(text) = self.slot(lang) {
            return Resolved::Exact(text);
        }
        if let Some(text) = self.zh_cn {
            return Resolved::Fallback {
                text,
                from: Lang::ZhCn,
            };
        }
        if let Some(text) = self.en_us {
            return Resolved::Fallback {
                text,
                from: Lang::EnUs,
            };
        }
        if let Some(text) = self.ja_jp {
            return Resolved::Fallback {
                text,
                from: Lang::JaJp,
            };
        }
        if let Some(text) = self.ko_kr {
            return Resolved::Fallback {
                text,
                from: Lang::KoKr,
            };
        }
        Resolved::Missing
    }
}
```

**`crates/definitions/src/generated/localized.rs`**

```rust

/// 取用结果：**缺语言显式报告回退**（D56）。
#[derive(Clone, Copy, PartialEq, Eq, Debug)]
pub enum Resolved {
    /// 正好是请求的语言。
    Exact(&'static str),
    /// 请求的语言缺失，回退到 from 那个语言（结果不是请求语言，调用方必须能看见）。
    Fallback {
        /// 回退后拿到的原文。
        text: &'static str,
        /// 实际来自哪个语言。
        from: Lang,
    },
    /// 一个语言都没有。
    Missing,
}
impl Resolved {
    /// 取文本（Missing 时为 None）；**不吞掉**「这是回退」这件事。
    pub const fn text(self) -> Option<&'static str> {
        match self {
            Resolved::Exact(text) | Resolved::Fallback { text, .. } => Some(text),
            Resolved::Missing => None,
        }
    }

    /// 是否正好命中请求语言。
    pub const fn is_exact(self) -> bool {
        matches!(self, Resolved::Exact(_))
    }

    /// 是否是回退（请求语言缺失，用了别语言）。
    pub const fn is_fallback(self) -> bool {
        matches!(self, Resolved::Fallback { .. })
    }

    /// 是否一个语言都没有。
    pub const fn is_missing(self) -> bool {
        matches!(self, Resolved::Missing)
    }

    /// 回退来源（Exact / Missing 时为 None）。
    pub const fn fallback_from(self) -> Option<Lang> {
        match self {
            Resolved::Fallback { from, .. } => Some(from),
            _ => None,
        }
    }
}
```
## 4. Invariants and prohibitions

> [!IMPORTANT]
> One tag, one file, one zero-sized type; there is no "all-tags enum" and no numeric / string code (D54).
> Tag text exists exactly once (`TAGS`): no text literals in tag files; runtime identity = field address (D67).

- Import only the concrete tag at its final path, e.g. `use crate::tags::action_card::support::location::Location;`.
- A tag shared across families imports the single definition site (D55); a second type / data copy is forbidden.
- Missing languages must go through the explicit `Resolved` fallback; do not hand-roll silent substitution with `slot()`.
- The tag-set shape (tuple / Vec / bitmap) is undecided this round; do not introduce a global bitmap unilaterally.

## 5. Basis (rulebook and D-numbers)

> [!NOTE]
> Data source: `generated/data/terms.json` -> generated by `build.rs`; nothing is read from files at runtime.
> The full tag set comes from in-game text: currently 52 tags; the rule table implements 51 of them (excluding automaton cards, see [[定义层-Rules-EN]]).

| Number | Conclusion |
|---|---|
| D53 / D54 | Tags are zero-sized types, one file per tag — not enums / numbers / strings |
| D55 | Each tag has exactly one definition, all created (52); shared tags import the definition site |
| D67 | Runtime identity = the address of `&TAGS.<field>`; field access performs no lookup |
| D56 / D68 | Languages are enum values, missing ones fall back explicitly (`Resolved`); field naming is fixed |
| D62 | Rich text keeps its markers; rendering happens in `generated::text` |

## 6. Common misuse

> [!WARNING]
> These patterns create a second copy of tag data or silently substitute a missing language; the relevant tests fail.

1. Adding a tag type under `tags/` but forgetting its entry in `terms.json`: `TAGS` has no such field and `data()` fails to compile.
2. Writing a name string inside a tag file: violates "one copy of data".
3. Using `tag as usize` / `TypeId` as identity: identity is a data address.
4. Reading `slot()` as valid text when the requested language is missing: inspect `Resolved`.
5. Treating `tags/status/` as the complete tag set: data has no tags for statuses, and it is empty this round.
